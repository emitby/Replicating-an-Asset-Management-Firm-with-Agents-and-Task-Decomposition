# Guardrails

Guardrails are enforced **in code**, at three points: when a tool is called, when the harness validates a stage, and in the evals. Prompts describe them so agents comply on the first try, but compliance never depends on the prompt.

## 1. Project guardrails (from CLAUDE.md)

| Rule | Enforcement |
|---|---|
| Never access files outside the project | `strategy.paths.confine()` resolves every path and raises `ConfinementError` if it's outside the project. All writes go through `write_text` / `write_json`. Tested in `test_confine_rejects_outside_paths` and in the red-team path cases. |
| No `import os` | `test_no_os_import_anywhere` scans every `.py` file. pathlib, `secrets` and `Path.replace` cover what `os` would do. |
| No OS or system configuration access | No environment reads or writes in Python. Library cache locations (`MPLCONFIGDIR`, `PYTHONPYCACHEPREFIX`) are set by `run.ps1` / `run.sh`, and yfinance's cache is set through its API. |
| Never delete files | Nothing in the code deletes. Runs go to new timestamped directories under `runs/`. Writes are atomic: write `*.tmp`, then rename. Test scratch files go to `.pytest_tmp/`, which is gitignored and never cleaned automatically. |
| Code can't modify anything outside the project | `charts.assert_cache_confined()` refuses to render if matplotlib's cache is outside the project. pip installs use `--no-cache-dir`. |

## 2. Numeric faithfulness

`strategy/guardrails.py`

- Every number in agent-written text (slides, findings) is extracted with its precision and unit.
- It must match a value in `analytics.json`, `backtest.json` or the data report (raw, ×100 for percentages, or absolute value), **at the precision written**, or one of the configured constants (5/20/50/200, 5 bps, 60/40, 3 years, $10,000 and so on).
- Calendar years are ignored. Tokens like `MA200` aren't treated as numbers.
- A violation is returned to the agent as a tool error naming the bad numbers, and the agent rewrites. The harness re-checks all slides before accepting the stage. `narrative_faithfulness` re-checks the final artifacts.

**Limitations:** a small integer like "2" can coincidentally match some stored value. The check proves every number *exists in the results*, not that it's used in the right sentence. The evals and visual review cover the semantics.

## 3. Compliance language

Blocked patterns include "guaranteed", "risk-free return", "can't lose", "no risk", "will outperform / beat / deliver", "certain to" and "proven to beat". See `BANNED_PATTERNS`.

## 4. Compliance content is owned by code, not agents

| Content | Owner |
|---|---|
| "Hypothetical backtested performance…" footer | `pdf.Deck`: added to any slide with a chart or a number, and to every table page. The agent can't turn it off. |
| Important Disclosures page | `pdf.DISCLOSURES`, always appended last |
| IN-SAMPLE labeling of the MA comparison | The `in_sample_comparison` page, generated by code |
| Metrics tables | Rendered from `analytics.json`, not written by an agent |
| "AI-generated fictional persona" stamp | Printed on every team card by the renderer |

## 5. Fictional team

`strategy/team.py`, a pydantic schema:

- exactly 1 Portfolio Manager and 5 analysts, with distinct focuses and unique names
- certifications from an allowlist: CFA, CAIA, FRM, CMT, CPA, CQF, PRM, CIPM
- employers checked against a list of well-known real firms (word-boundary match), so personas can't claim real affiliations
- names checked against well-known finance figures
- bio length bounds and graduation-year bounds

Real universities are allowed, since every card and the disclosures label the personas as fictional.

## 6. Agent limits

- Each agent has only the tools for its job (`docs/agents.md`).
- Tool arguments are checked against the handler's signature before execution.
- Enums restrict tickers, MA lengths, windows, chart kinds and page types.
- Turn limits: 20 per agent by default, 8 for Team, 40 for Presentation.
- A run-wide token budget (3M tokens by default) raises `BudgetExceeded`.
- A refusal returns a safe reply, and server-side fallbacks (`fallbacks="default"`) handle policy declines.
